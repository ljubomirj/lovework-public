# Roadmap

LoveWork is being published documentation-first. The roadmap intentionally
separates having a public idea and address from claiming that a general product
is ready.

## Now — public foundation

- Publish the motivation, manifesto, profile model, architecture, and privacy
  principles.
- Provide a fictional profile and synthetic output that can be discussed
  without exposing anyone's personal data.
- Keep the working personal installation running and learning.
- Establish the public repository and project identity.

## Next — reusable engine

- Separate generic engine code from personal adapters and configuration.
- Define stable interfaces for sources, profiles, history, assessment, and
  output stores.
- Add a self-contained demonstration using only synthetic fixtures.
- Publish the reusable engine and its tests under Apache-2.0.
- Add structured ATS sources and improve long-page extraction.

## Later — a product for more people

- Build a private-by-default local or hosted user experience.
- Support multiple kinds of work beyond conventional vacancies.
- Let people inspect, correct, and version what the agent believes about them.
- Learn from decisions and outcomes without pooling identifiable personal
  histories.
- Evaluate recommendation quality longitudinally, not merely by clicks or
  application volume.
- Explore carefully curated public opportunity views without exposing private
  reasoning or creating another indiscriminate job feed.

## Continuing principles

- A person is more than a CV.
- Privacy is an architectural boundary, not a promise added later.
- The agent should explain its judgment and uncertainty.
- Human decisions override model output.
- Success means better lives and better-fit work, not more applications.
