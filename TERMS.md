# Terms of Service

LoveWork is personal software that helps people discover meaningful work.
These terms govern use of the LoveWork application and its associated
Google API integrations.

## Data access

LoveWork accesses Google account data (Gmail, Calendar, Drive, Contacts,
Sheets, Docs) solely to support the user's personal work-discovery
workflow. Data is processed locally on the user's own infrastructure.
LoveWork does not transmit, store, or share Google account data with
third parties.

## Google API compliance

Use of Google APIs through LoveWork is subject to
[Google's Limited Use Requirements](https://developers.google.com/workspace/guides/data-usage-policy).
LoveWork adheres to these requirements:

- Data accessed through Google APIs is used only to provide the service
  the user has requested.
- Human-readable data is not transferred to other humans or used for
  advertising.
- Data is not used for purposes other than providing the user's personal
  work-discovery features.

## User responsibility

The user controls their own data, profiles, and configurations. LoveWork
operates as a local agent — it does not operate a hosted service, collect
analytics, or maintain user accounts beyond the local installation.

software after changes constitutes acceptance of the revised terms.
