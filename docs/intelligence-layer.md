# The Intelligence Layer

Crawlers, language models, databases, and dashboards are replaceable parts.
The enduring part of LoveWork is the longitudinal judgment loop connecting a
particular person to opportunities over time.

## Persona and circumstance model

The agent needs a revisable model of the person's capabilities, motivations,
constraints, working style, and possible futures. This is richer than a
search query and more dynamic than a CV.

## Opportunity interpretation

The same listing can be an excellent direction for one person, a useful
stretch for another, and a costly distraction for a third. The intelligence
layer interprets evidence in context rather than assigning universal job
quality.

## Decision ledger

Each recommendation creates an observation:

```text
what the agent saw
    -> what it inferred
    -> what it recommended
    -> what the person decided
    -> what eventually happened
```

Keeping these stages distinct makes judgments inspectable and creates the
evidence needed to improve them.

## Feedback harness

Feedback includes more than explicit ratings. Ignoring a suggestion, returning
to it later, applying, interviewing, declining, being rejected, thriving, or
leaving quickly are all different signals. None is self-explanatory; the
agent should preserve context and uncertainty rather than collapse every event
to a binary reward.

## Future-self criterion

The central assessment question is:

> Would a future version of this person be glad that they pursued this
> opportunity now?

This brings reach, fit, flourishing, timing, reversibility, and opportunity
cost into the same decision without pretending they form a perfectly objective
score.

## Why longitudinal data stays private

The decision ledger becomes an unusually intimate account of a person's
ambitions, setbacks, relationships, and changing circumstances. Open software
can implement the loop; an individual's ledger should remain under their
control.
