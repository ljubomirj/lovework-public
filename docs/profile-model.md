# The Profile Model

LoveWork represents a person in layers. No single document is expected to be a
complete or permanent account.

## Layer 1 — the long path

The long path records the broader past: education, work, projects, transitions,
interests, repeated themes, and experiences that do not fit a short CV. It is
high-context and loaded only when the decision warrants the additional detail.

Typical public-example file: `bio-long.md`.

## Layer 2 — the current tip

The current tip is the highest-signal account of what the person can credibly
offer now. It resembles a short CV, but is treated as a present projection of a
larger life rather than the person's identity.

Typical file: `cv-short.md`.

## Layer 3 — branching possibilities

The possibilities layer describes several plausible futures. Some branches
may be adjacent to current work; others may depend on an unusual combination
of experience, a new collaboration, or deliberate preparation.

Typical file: `possibilities.md`.

## Cross-cutting context

Additional documents express information that does not fit neatly into the
three time-oriented layers:

- `soul.md`: values, motivations, working style, attractions, and aversions;
- `work_auth.md`: location, authorisation, availability, and other hard
  constraints;
- `roles/*.md`: temporary criteria for a particular search or direction.

## How assessment uses the layers

Hard constraints are evaluated first. The current tip and possible futures
then guide normal assessment. The long path is consulted when a surprising
opportunity might make sense only in the context of earlier experience.

The profile is evidence for a conversation, not an oracle. The person can
correct it; conflicting statements should remain visible; uncertainty should
be represented rather than silently resolved by the model.

See [`examples/profile/`](../examples/profile/) for a fictional example.
